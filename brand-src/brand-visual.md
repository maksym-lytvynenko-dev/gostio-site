# Gostio — визуальная система

Шаг 2 плана: логотип, знак, фавикон, палитра, шрифтовая пара, светлая и тёмная версии, OG-картинка.
Текстовая часть бренда — в `../brand-gostio.md` и `../brand.json`.

> Все контакты, телефоны и адреса в проекте — **заглушки** (`"_placeholder": true` в `brand.json`).
> Логотип и айдентика придуманы под демо-задачу.

---

## 1. Знак

Открытое кольцо «G» с медной перекладиной. Кольцо — стол/тарелка и буква G одновременно,
медная перекладина — реплика ассистента: линия, которая замыкает разговор.

- Геометрия: `viewBox 0 0 64 64`, радиус 22, `stroke-width 9`, `stroke-linecap="round"`.
- Знак живёт в квадрате 64×64 и масштабируется целиком, пропорции не меняются.
- Минимальный размер знака — **16 px** (проверено, см. `src/logo-sheet.html`).

| Файл | Где применять |
|---|---|
| `gostio-mark.svg` | знак на светлом фоне (ink + copper) |
| `gostio-mark-dark.svg` | знак на тёмном фоне (paper + copper-300) |
| `gostio-mark-mono.svg` | одноцветный, наследует `currentColor` — печать, штамп, one-color |

## 2. Логотип (локап)

Знак + начертание «Gostio» в Manrope 800, горизонтально, по оптическому центру.

- Зазор между знаком и словом: **0.30 em** от кегля начертания.
- Высота знака: **0.95 em** от кегля начертания.
- Трекинг начертания: **−0.025 em**.
- Охранное поле вокруг логотипа: **0.5 × высоты знака** со всех сторон.
- Минимальная высота логотипа целиком: **20 px** (ниже — только знак).

| Файл | Что это |
|---|---|
| `gostio-logo-light.svg` | полный логотип, тёмный текст — для светлого фона |
| `gostio-logo-dark.svg` | полный логотип, светлый текст — для тёмного фона |
| `gostio-logo-light.png` / `gostio-logo-dark.png` | растровые мастера, прозрачный фон, высота ~130 px |

⚠️ **Важно про SVG-логотипы.** В них текст — живой `<text>` в Manrope.
Он отрисуется правильно, только если SVG **вставлен инлайном в HTML** на странице
с подключённым Manrope. В `<img src="logo.svg">` внешние шрифты не грузятся и слово
съедет на системный шрифт. Поэтому **на сайте используйте HTML-локап** (см. ниже) —
это самый надёжный вариант, он же и отзывчивый.

### HTML-локап для шапки (рекомендуемый способ)

Класс `.g-logo` уже есть в `tokens.css`. Размер задаётся **одним** свойством `font-size`:

```html
<a class="g-logo" href="/" aria-label="Gostio">
  <img src="/brand/gostio-mark.svg" alt="" width="24" height="24">
  <span>Gostio</span>
</a>
```

```css
.g-logo        { font-size: 22px; }   /* шапка */
.g-logo--foot  { font-size: 20px; }   /* футер */
```

Для тёмной шапки подменяйте `src` на `gostio-mark-dark.svg` (через `<picture>` с
`media="(prefers-color-scheme: dark)"` или переключателем темы).

**Грабли, на которые я уже наступил:** если написать `height: .95em` на `<img>`,
не задав `font-size` на контейнере `.g-logo`, `em` посчитается от унаследованных 16 px,
и знак схлопнется до крошечного. Кегль задаётся именно на контейнере.

## 3. Фавикон и иконки

`favicon.svg` — знак на тёмной плашке со скруглением 16/64 (= 25 %). Плашка нужна:
тонкое кольцо без неё теряется на светлой вкладке. Медиазапрос не нужен — тёмная
плашка одинаково читается в обеих темах.

| Файл | Размер | Разметка |
|---|---|---|
| `favicon.svg` | вектор | `<link rel="icon" href="/favicon.svg" type="image/svg+xml">` |
| `favicon-32.png` | 32×32 | `<link rel="icon" href="/favicon-32.png" sizes="32x32">` |
| `apple-touch-icon.png` | 180×180, без скругления | `<link rel="apple-touch-icon" href="/apple-touch-icon.png">` |
| `gostio-icon-512.png` | 512×512, скругление 112 | иконка PWA / манифест |
| `gostio-mark-512.png` | 512×512, прозрачный | универсальный растровый знак |

## 4. Палитра

Контраст посчитан по WCAG 2.1 относительно cream `#FAF6F0` (светлая тема)
или night `#141110` (тёмная).

| Токен | HEX | Контраст | Роль |
|---|---|---|---|
| `--g-ink` | `#1A1715` | 16.0:1 на cream | основной текст, знак на светлом |
| `--g-muted` | `#5F544E` | 6.5:1 на cream | вторичный текст, подписи |
| `--g-copper` | `#C2643C` | 3.67:1 на cream | **только** графика и текст от 24 px |
| `--g-copper-600` | `#A84F2A` | 5.0:1 с белым текстом | кнопки, ссылки, мелкий акцент |
| `--g-copper-300` | `#E08A5C` | 6.9:1 на night | акцент в тёмной теме |
| `--g-sand` | `#F3EADF` | — | фон секций |
| `--g-cream` | `#FAF6F0` | — | фон страницы, светлая тема |
| `--g-paper` | `#F4ECE3` | 15.4:1 на night | текст в тёмной теме |
| `--g-night` | `#141110` | — | фон страницы, тёмная тема |
| `--g-line` | `#E6DACA` | — | границы, разделители |
| `--g-sage` | `#4E7A5E` | — | статус «бронь подтверждена» |

**Правило акцента.** `#C2643C` не проходит AA для основного текста — не красьте им
абзацы и мелкие подписи. Для ссылок и кнопок берите `--g-copper-600`, в тёмной
теме — `--g-copper-300`. В `tokens.css` это уже разведено на `--g-accent`
(графика) и `--g-accent-strong` (текст и интерактив).

Пропорция на странице: ~70 % нейтрального фона, ~25 % ink/текста, ~5 % меди.
Медь — для одной главной кнопки в экране, акцентного слова в заголовке и статусов.

## 5. Шрифтовая пара

- **Manrope** 700/800 — начертание логотипа, заголовки. Мягкий геометрический гротеск,
  полная кириллица, хорошо смотрится в крупном кегле с отрицательным трекингом.
- **Inter** 400/500/600 — весь текст и интерфейс.

```html
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Manrope:wght@500;700;800&family=Inter:wght@400;500;600&display=swap">
```

| Роль | Шрифт | Кегль | Интерлиньяж | Трекинг |
|---|---|---|---|---|
| Hero | Manrope 800 | 36 → 64 px (`--g-fs-hero`) | 1.06 | −0.028 em |
| H2 | Manrope 800 | 26 → 40 px | 1.18 | −0.028 em |
| H3 | Manrope 700 | 20 → 24 px | 1.18 | −0.02 em |
| Лид | Inter 400 | 17 → 20 px | 1.5 | 0 |
| Текст | Inter 400 | 16 px | 1.6 | 0 |
| Кнопки, меню | Inter 500/600 | 15–16 px | 1 | 0 |
| Надзаголовки | Manrope 800 | 13 px, uppercase | 1 | +0.14 em |

Длина строки в абзацах — **60–70 знаков** (`max-width: 65ch`).
Fraunces и другие «вкусные» антиквы не берём: в них нет кириллицы, а сайт русский.
Если понадобится акцентная антиква для цитат — **Literata** (кириллица есть).

## 6. Светлая и тёмная темы

`tokens.css` даёт семантические переменные (`--g-bg`, `--g-text`, `--g-accent` …),
которые переключаются:

1. автоматически по `@media (prefers-color-scheme: dark)`;
2. вручную через `<html data-theme="dark">` / `data-theme="light"`.

Верстать нужно **только** семантическими токенами, базовые (`--g-ink`, `--g-cream`)
трогать в компонентах не надо — иначе тёмная тема сломается.

## 7. OG-картинка

`og-image.png`, 1200×630 — логотип, заголовок «Ни одного пропущенного **гостя**.»,
подзаголовок и три «чипа» (`Звонки · WhatsApp · Брони`, `RU · BG · EN`, `gostio.ai`)
на тёмном фоне с тёплым боке справа. Фон собран CSS-градиентами, внешних картинок нет.

```html
<meta property="og:image" content="https://<домен>/og-image.png">
<meta property="og:image:width" content="1200">
<meta property="og:image:height" content="630">
<meta property="og:image:alt" content="Логотип Gostio и таглайн «Ни одного пропущенного гостя»">
<meta name="twitter:card" content="summary_large_image">
```

Остальные meta-строки (title, description) — в `brand.json`, раздел `meta`.
`og:image` должен быть **абсолютным** URL, иначе превью не соберётся.

## 8. Можно / нельзя

**Можно**
- масштабировать логотип целиком, задавая `font-size` на `.g-logo`;
- ставить знак отдельно, без слова, — в аватарках, фавиконе, мелких местах;
- класть логотип на фото, если под ним есть тёмная вуаль (как в OG-картинке).

**Нельзя**
- перекрашивать медную перекладину в другой цвет или убирать её — это единственная
  цветная деталь знака;
- растягивать, наклонять, добавлять тень или обводку;
- набирать «Gostio» другим шрифтом или другим начертанием Manrope;
- ставить тёмный знак на тёмный фон и наоборот — для этого есть парные версии;
- заполнять кольцо цветом: оно всегда открытое и без заливки.

## 9. Состав папки

```
brand/
├── brand-visual.md          ← этот файл
├── tokens.css               ← CSS-переменные + класс .g-logo, подключать первым
├── gostio-mark.svg          ← знак, светлый фон
├── gostio-mark-dark.svg     ← знак, тёмный фон
├── gostio-mark-mono.svg     ← знак, currentColor
├── gostio-logo-light.svg    ← полный логотип (см. оговорку про шрифт в §2)
├── gostio-logo-dark.svg
├── favicon.svg
└── src/                     ← исходники, из которых сняты PNG
    ├── logo-sheet.html      ← тестовый лист: размеры, палитра, шрифты
    ├── export.html          ← блоки для PNG-экспорта (по id)
    └── og-image.html        ← OG-карточка 1200×630
```

PNG-мастера лежат отдельно, пути к ним — в хендоффе шага 2.
Их нужно скопировать в репозиторий сайта под именами:
`og-image.png`, `gostio-logo-light.png`, `gostio-logo-dark.png`,
`gostio-mark-512.png`, `gostio-icon-512.png`, `apple-touch-icon.png`, `favicon-32.png`.
